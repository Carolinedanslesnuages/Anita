# Anita

Une carte interactive qui efface les limites administratives habituelles (communes, départements, régions) pour révéler le territoire naturel auquel on appartient réellement : celui de l'eau.

Carte interactive créée avec ADA (Vue 3, DSFR, MapLibre, fond de carte IGN) : des lieux sur une
carte et dans une liste accessible, avec des filtres. Fiche projet : [PROJET.md](PROJET.md) ;
consignes pour les agents de code : [AGENTS.md](AGENTS.md) ; décisions : [docs/adr/](docs/adr/README.md).
